# CaterPro UI and workflow update — 2026-11-04

- Reporting attendance now toggles between Present (green check) and Absent (red); blank attendance is treated and displayed as Absent.
- Reporting summary metric cards and count strip have reduced vertical padding; attendance changes trigger an immediate screen rebuild and auto-save.
- Removed the large Event Billing Overview banner from Outing Billing and tightened the venue/date/expense details card.
- Removed the Dashboard Event Management Open button; the complete Event Management card is now tappable.
- Event cards show the event name and site clearly. Tapping an event opens a copyable Event Details summary with date, site, Boys, SP, CP, Hosting, Total Staff and Total TA. Bill management remains available from the event overflow menu.
- Dark theme now uses a true black scaffold/app bar and near-black surfaces, with dark-compatible reporting and outing row backgrounds.
- Gradle wrapper remains set to Gradle 8.14.3, Android Gradle Plugin 8.11.1, Kotlin 2.2.20, Java 17 and compileSdk 36.
